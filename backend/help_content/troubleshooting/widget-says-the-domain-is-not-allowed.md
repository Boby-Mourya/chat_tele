# Widget says the domain is not allowed

The Website widget blocks a host that is not permitted by the agent allowlist.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Recovery steps

Open the agent/Deploy allowed-domain controls, compare the exact browser hostname, add the intended trusted domain, save, and retest. Do not disable protection for all sites as the first fix.

## If it still fails

Use **Help → Contact support**. Include safe diagnostic context and the smallest reproducible description of the problem. The Help Center stores the support destination that was active when the request was submitted.
