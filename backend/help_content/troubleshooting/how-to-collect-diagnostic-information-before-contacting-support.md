# How to collect diagnostic information before contacting support

Safe diagnostics help support reproduce a problem without collecting customer secrets.

## Before you start

This guide is available to all authenticated workspace roles.

## Recovery steps

Include the current route, your workspace role, browser user agent, app/build version if visible, timestamp, and a short description of the action/error. Never include access tokens, refresh tokens, passwords, API keys, Meta tokens, full conversation contents, or customer knowledge text.

## If it still fails

Use **Help → Contact support**. Include safe diagnostic context and the smallest reproducible description of the problem. The Help Center stores the support destination that was active when the request was submitted.
