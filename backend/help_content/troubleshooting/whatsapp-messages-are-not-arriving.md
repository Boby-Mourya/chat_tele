# WhatsApp messages are not arriving

A connected badge alone does not guarantee every external webhook/message path is healthy.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Recovery steps

Verify the correct WhatsApp business/phone setup, the intended agent assignment, backend webhook availability, and recent integration status. Avoid disconnecting/reconnecting until you have checked whether events are reaching the backend.

## If it still fails

Use **Help → Contact support**. Include safe diagnostic context and the smallest reproducible description of the problem. The Help Center stores the support destination that was active when the request was submitted.
