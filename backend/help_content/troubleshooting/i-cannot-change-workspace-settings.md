# I cannot change Workspace settings

Workspace configuration changes require Owner/Admin access.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Recovery steps

Confirm your membership role. If you have permission, reload Workspace, retry the specific save, and capture the error message without exposing secrets. Do not work around the backend authorization check.

## If it still fails

Use **Help → Contact support**. Include safe diagnostic context and the smallest reproducible description of the problem. The Help Center stores the support destination that was active when the request was submitted.
