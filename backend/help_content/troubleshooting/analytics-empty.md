# Analytics looks empty

1. Confirm the workspace has conversation activity for the selected period.
2. Verify you are in the expected workspace.
3. Compare **Conversations** with the analytics period.
4. Refresh after recent activity has time to process.
5. If activity exists but Analytics is empty, submit a support request with non-secret context.
