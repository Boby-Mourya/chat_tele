# Knowledge is stuck processing or failed

1. Open the agent **Knowledge** tab and inspect source state.
2. Refresh after normal ingestion time.
3. If **Failed**, review the visible error and validate the source/file.
4. If many sources are stuck, verify background ingestion services.
5. Correct and replace/re-add the source as needed.

If contacting support, include source name/status but no credentials.
