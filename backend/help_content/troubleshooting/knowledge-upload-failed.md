# Knowledge upload failed

A knowledge file can fail before or during ingestion.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Recovery steps

Confirm PDF/DOCX/TXT/Markdown format, a maximum upload size of 500 MB by default, matching content type/extension, and a healthy object-storage/ingestion backend. Then retry once with a known-good file.

## If it still fails

Use **Help → Contact support**. Include safe diagnostic context and the smallest reproducible description of the problem. The Help Center stores the support destination that was active when the request was submitted.
