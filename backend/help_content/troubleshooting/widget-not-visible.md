# The website widget does not appear

1. Confirm the intended agent is published/selected in **Deploy**.
2. Verify the current embed snippet is present on the website.
3. Check **Allowed domains** for the real hostname.
4. Reload and inspect browser console/network errors if you manage the site.
5. Test the hosted/demo preview to separate configuration from site installation.
