# My session expired

Your access session can expire as part of normal authentication security.

## Before you start

This guide is available to all authenticated workspace roles.

## Recovery steps

Return to the sign-in page, authenticate again, and then retry the original action. If refresh repeatedly fails, clear only the application session through the normal sign-out/sign-in flow rather than editing tokens manually.

## If it still fails

Use **Help → Contact support**. Include safe diagnostic context and the smallest reproducible description of the problem. The Help Center stores the support destination that was active when the request was submitted.
