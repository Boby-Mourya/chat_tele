# WhatsApp is not connected

The WhatsApp card/channel needs an active workspace connection before normal deployment.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Recovery steps

Open Integrations as Owner/Admin, run Embedded Signup or Manage, complete Meta authorization, and verify the card shows Connected. Then return to Deploy.

## If it still fails

Use **Help → Contact support**. Include safe diagnostic context and the smallest reproducible description of the problem. The Help Center stores the support destination that was active when the request was submitted.
