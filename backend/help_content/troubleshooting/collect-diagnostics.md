# Collect safe diagnostic information

Useful support context includes the current route, workspace role, browser user agent, app/build version when available, approximate time, and visible request/error ID.

Do not include access tokens, refresh tokens, passwords, API keys, Meta tokens, full conversation contents, or customer knowledge content.
