# I cannot sign in

1. Confirm the correct account email and workspace.
2. Re-enter the password carefully.
3. If the session expired, return to login and sign in again.
4. Confirm the user is active and still has a workspace membership.
5. If the problem continues, contact the workspace administrator or support.

Never send your password in a support request.
