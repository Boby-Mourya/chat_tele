# I cannot create or edit an agent

Agent write operations require Owner/Admin access.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Recovery steps

Confirm your workspace role, then reopen Agents. If you are an Owner/Admin and the save still fails, check the form error/toast and backend availability. Do not create a second agent merely to hide a failing save.

## If it still fails

Use **Help → Contact support**. Include safe diagnostic context and the smallest reproducible description of the problem. The Help Center stores the support destination that was active when the request was submitted.
