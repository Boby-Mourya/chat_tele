# Protect integration and API credentials

Never place access tokens, refresh tokens, passwords, API keys, Meta credentials, or other secrets into Help requests, Help AI questions, agent instructions, knowledge uploads, or unapproved screenshots.

If a credential may be exposed, revoke or rotate it using the correct provider or Northstar control.
