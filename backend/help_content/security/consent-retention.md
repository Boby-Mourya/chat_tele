# Understand consent and retention settings

Agent configuration can include consent messaging, a privacy-policy URL, and retention-related settings.

1. Open agent settings/security.
2. Review consent and privacy options.
3. Use clear user-facing wording that matches your actual processing.
4. Configure retention according to your requirements.
5. Save and test the widget experience before deployment.
