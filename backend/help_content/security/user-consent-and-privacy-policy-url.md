# User consent and privacy policy URL

Website deployment settings can require visitor consent and display your privacy-policy destination before processing conversations.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Steps

1. Open the relevant agent/deployment privacy controls.
2. Enable consent when your policy requires it.
3. Write a clear **Consent message**.
4. Set the **Privacy policy URL** to the organization's published policy.
5. Preview the customer flow before deploying.

## Important

Northstar configuration tools do not replace legal review. Use language and behavior approved for your organization and jurisdiction.

## Troubleshooting

If the consent UI does not appear, verify the latest agent/deployment settings were saved and the same agent is selected in the Website preview.
