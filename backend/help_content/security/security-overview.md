# Northstar security and privacy overview

Northstar includes authentication/roles plus controls such as allowed domains, rate limiting, sensitive-data masking, data retention, consent messaging, and privacy-policy configuration where exposed by the current UI.

Owners/Admins should configure these controls to match organizational requirements. All users should avoid placing secrets or unnecessary personal data into support requests.
