# Choose an agent template/purpose

The **Starting point** in the creation flow supplies safe starter instructions for the agent's main job.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Available starting points

- **Start from scratch** — build custom instructions yourself.
- **Customer support** — start from a support-oriented configuration.
- **Lead qualification** — start from a lead-capture/qualification configuration.

## Steps

1. Open **Agents → Create agent**.
2. Complete the name/description step.
3. On **Choose its main job**, select the starting point that is closest to the real use case.
4. Continue through tone/language and deployment channel.
5. After creation, open **Instructions** and customize the starter guidance.

## What happens next

Templates are a starting point, not a replacement for trusted knowledge and clear instructions.
