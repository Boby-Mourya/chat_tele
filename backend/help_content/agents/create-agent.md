# Create an agent

## Before you start

You need an **Owner** or **Admin** role.

1. Open **Agents**.
2. Select **Create agent**.
3. Enter the agent basics.
4. Choose its main job/template.
5. Configure **Voice & language**.
6. Choose a deployment channel: Website, WhatsApp, Instagram, Facebook, Slack, Teams, API, Notion, or Zapier where supported.
7. Finish creation and open the agent workspace.

Review configuration before publishing.
