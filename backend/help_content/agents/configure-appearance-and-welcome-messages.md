# Configure appearance and welcome messages

Use **Widget appearance** and Deploy customization to make the customer-facing experience match your brand.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Steps

1. Open the agent's **Settings**.
2. Under **Widget appearance**, set **Primary color** and **Widget placement**.
3. Edit **Hero heading**, **Greeting message**, and **Message placeholder**.
4. Add **Conversation starters**, one question per line.
5. Choose whether to **Show Northstar branding**.
6. Save, then open **Deploy** to preview desktop and mobile behavior.

## What happens next

The Website preview reflects the agent's appearance configuration. Channel-specific previews can present the same content in a different channel layout.

## Troubleshooting

If the preview looks different from the live site, confirm the same agent is selected in Deploy and that the newest settings were saved.
