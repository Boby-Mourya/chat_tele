# Configure an agent

Open an agent from **Agents**.

- **Instructions** define the agent's approved operating guidance.
- **Knowledge** supplies sources used for grounded retrieval.
- **Settings** exposes model, tone/language, appearance, and security controls supported by the current UI.
- **Embeddings & deployment** shows retrieval/deployment information.

Save changes after editing. Do not place passwords, API keys, or provider tokens in instructions.
