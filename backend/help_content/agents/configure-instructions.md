# Configure instructions

Instructions define how an agent should behave when it answers.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Steps

1. Open **Agents** and select the agent.
2. Open the **Instructions** tab.
3. Describe the agent's job, boundaries, escalation behavior, and response expectations in clear language.
4. Keep product facts in **Knowledge** rather than copying large documents into instructions.
5. Save the changes.
6. Test representative and out-of-scope questions.

## Good practice

Keep instructions specific and stable. Do not paste passwords, API keys, provider tokens, customer secrets, or hidden credentials into instructions.

## Troubleshooting

If instructions conflict with trusted source content, simplify the instructions and make the knowledge source authoritative for factual details.
