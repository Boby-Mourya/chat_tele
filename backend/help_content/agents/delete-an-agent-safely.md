# Delete an agent safely

Deleting an agent removes its active configuration and deployment settings. The current confirmation message states that conversation history is retained according to the workspace data policy.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Steps

1. Open **Agents**.
2. Open the action menu for the agent.
3. Select **Delete**.
4. Verify the agent name and knowledge-source count in the confirmation.
5. Select **Delete agent** only when you are sure the deployment is no longer needed.

## Before deleting

Check which websites/channels use the agent and whether another agent has already replaced it.

## Troubleshooting

If Delete is unavailable or rejected, confirm the current account is an Owner/Admin. Do not work around authorization with direct API calls.
