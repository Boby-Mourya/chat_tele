# Understand the Agents page

**Agents** lists the AI agents available in your workspace. Each agent has its own workspace for instructions, knowledge, settings, and deployment information.

Agent status can include **active**, **draft**, **training**, or **error**. Owner and Admin roles can create and manage agents. Other authenticated roles can read agent information allowed by current backend permissions.
