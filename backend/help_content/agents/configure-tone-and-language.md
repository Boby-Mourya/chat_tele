# Configure tone and language

Tone and language control how the agent communicates, while Knowledge controls what facts it can ground answers on.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Steps

1. During creation, choose **Response tone** and **Primary language**.
2. Available tones include **Professional**, **Friendly**, **Concise**, **Empathetic**, and **Playful**.
3. Review the visitor preview before finishing creation.
4. For an existing agent, review its **Settings** and deployment localization options.
5. Test the same question in the intended language.

## What happens next

The language selection affects customer-facing labels, starter questions, typed conversations, and AI answers where the active UI supports it.

## Troubleshooting

If a deployment still shows old labels, check the localization settings in **Deploy** and apply/save the latest configuration.
