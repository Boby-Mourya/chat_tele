# Duplicate an agent for another channel

1. Open the existing agent action menu.
2. Choose **Duplicate**.
3. Give the copy a name.
4. Choose its deployment channel.
5. Confirm duplication.

The duplicate keeps the source agent's configured instructions/settings as a starting point while receiving the selected deployment channel. Review the copy before publishing.
