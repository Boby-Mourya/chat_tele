# Create, test, and deploy your first agent

## Before you start

You need an **Owner** or **Admin** role.

## Steps

1. Open **Agents** and select **Create agent**.
2. Complete the guided Basics, purpose/template, Voice & language, and deployment-channel steps.
3. Open the agent and review **Instructions**, **Knowledge**, **Settings**, and **Embeddings & deployment**.
4. Add approved knowledge when grounded answers are required.
5. Test the agent.
6. Open **Deploy**, select the agent, and use the preview or installation option for its channel.
