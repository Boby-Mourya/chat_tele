# Test your agent before deployment

Use Northstar previews to verify content, appearance, and channel behavior before customers see the agent.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Steps

1. Confirm important knowledge sources show **ready**.
2. Open the agent and review **Instructions** and **Settings**.
3. Open **Deploy** and select the same agent.
4. Select the intended **Deployment channel**.
5. Use the desktop/mobile preview where available and ask representative questions.
6. Confirm grounded answers, citations when enabled, welcome text, and conversation starters.
7. Test at least one question that is *not* in the knowledge base to make sure the agent does not invent unsupported information.

## What happens next

Only publish or share the deployment after the expected answers and recovery behavior look correct.

## Troubleshooting

If answers are weak, improve the knowledge source or instructions first; deployment settings do not repair retrieval quality.
