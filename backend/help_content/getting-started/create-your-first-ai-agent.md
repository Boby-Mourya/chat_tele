# Create your first AI agent

Create a focused assistant using the four-step **Create agent** flow.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Steps

1. Open **Agents** and select **Create agent**.
2. Enter **Agent name** and **What should it help with?**.
3. Under **Starting point**, choose **Start from scratch**, **Customer support**, or **Lead qualification**.
4. Choose **Response tone** and **Primary language**.
5. Choose a **Deployment channel** such as Website, WhatsApp, Instagram, Facebook / Meta, Slack, Microsoft Teams, Developer API, Notion, or Zapier.
6. Review the summary and select **Create agent**.

Northstar opens the new agent on the **Instructions** tab.

## What happens next

Add trusted content under **Knowledge**, review **Settings**, and test the correct channel preview before deployment.

## Troubleshooting

If creation fails, confirm you are an Owner/Admin and that the agent name and required fields are not empty.
