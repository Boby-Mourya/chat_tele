# Understand the Northstar workspace

Northstar keeps the main workflow in one authenticated application shell so you can move from configuration to operations without switching products.

## Before you start

This guide is available to all authenticated workspace roles.

## Main navigation

The sidebar follows this order: **Overview → Agents → Conversations → Leads → Analytics → Integrations → Deploy → Workspace → Help**.

- **Agents** is where AI assistants are created and configured.
- **Conversations** is the operational inbox.
- **Leads** contains captured contacts.
- **Analytics** explains usage and outcomes.
- **Integrations** connects supported channels.
- **Deploy** previews and publishes an agent to a channel.
- **Workspace** contains organization, team, developer, security, billing, and white-label settings that your role is allowed to use.
- **Help** opens this Help Center.

## What happens next

Start in **Agents** if you are setting up Northstar, or open **Conversations** if you are operating an existing deployment. Your workspace role controls which changes the backend will accept.

## Troubleshooting

If an action returns a permission error, check **Help → Workspace & Access → Owner, Admin, Member and Analyst permissions** before retrying.
