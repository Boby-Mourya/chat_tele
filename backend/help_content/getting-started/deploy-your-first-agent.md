# Deploy your first agent

Deploy connects a configured agent to the channel people will use.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Steps

1. Open **Deploy**.
2. Select the agent at the top of the deployment workspace.
3. Choose the **Deployment channel**.
4. For Website, configure appearance, launcher behavior, localization, privacy, and sharing options, then use **Instant embed** or **IFrame embed**.
5. For WhatsApp, use **Integrations** to connect WhatsApp Business first.
6. For other channels, follow the channel panel and note any **Coming soon** status.
7. Use the preview and test the deployment before sharing it broadly.

## What happens next

Future agent changes use the same agent configuration, so you normally do not need to recreate the agent.

## Troubleshooting

For Website problems, check the embed snippet, **Allowed domains**, agent status, and the browser console.
