# Understand the Analytics dashboard

Open **Analytics** to review conversation performance for the selected period. The current dashboard includes conversation volume, resolution rate, average response time, satisfaction, conversation/resolution charting, top questions, and channel distribution.

Use trends together instead of judging quality from one metric alone.
