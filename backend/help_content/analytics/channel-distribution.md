# Channel distribution

Channel distribution shows how conversation activity is split across channels such as the Web widget, API, Slack, or other connected surfaces.

## Before you start

This guide is available to all authenticated workspace roles.

## How to use this metric

Use it to decide which deployment needs the most testing and support coverage.

1. Open **Analytics**.
2. Use the currently selected reporting period.
3. Compare the metric with related metrics instead of reading it alone.
4. Investigate sudden changes against deployments, integrations, and agent changes made in the same period.

## Troubleshooting

If the metric is empty, confirm conversations exist for the selected period and refresh the dashboard before assuming data loss.
