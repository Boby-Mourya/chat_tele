# Improve retrieval quality

Use clear, authoritative sources that directly state the answers users need.

1. Remove contradictory or outdated material before uploading a replacement.
2. Use descriptive source names.
3. State important facts explicitly.
4. Test realistic questions after the source becomes Ready.
5. When the agent safely reports insufficient evidence, improve the source instead of forcing unsupported answers in instructions.
