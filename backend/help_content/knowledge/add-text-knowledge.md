# Add text knowledge

Use **Write text** for short, authoritative information that does not need a separate file.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Steps

1. Open **Agents → your agent → Knowledge**.
2. Select **Add source**.
3. Choose **Write text**.
4. Optionally enter **Source name**.
5. Paste or write the reliable content in **Knowledge content**.
6. Select **Add source** and wait for **ready**.

## Good use cases

Policies, short FAQs, escalation instructions, hours, or other concise facts that change independently from a document.

## Troubleshooting

If a long text source covers unrelated topics, split it into clearer sources so retrieval can match more precisely.
