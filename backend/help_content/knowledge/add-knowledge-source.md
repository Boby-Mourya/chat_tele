# Add a knowledge source

## Before you start

You need an Owner/Admin role and an existing agent.

1. Open **Agents** and choose the agent.
2. Open **Knowledge**.
3. Select **Add source**.
4. Choose the source type offered by the form, such as file, text, URL, or sitemap.
5. Submit the source.
6. Watch its status while ingestion runs.

Do not upload credentials or secrets as knowledge.
