# Verified facts / Q&A workflow

Verified facts let an Owner/Admin maintain high-confidence question-and-answer material separately from broad documents when the current workspace enables that workflow.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Recommended workflow

1. Identify a repeated question that needs an exact approved answer.
2. Add or review the fact/Q&A in the agent knowledge workflow.
3. Keep the wording factual, concise, and current.
4. Approve only information that is authoritative for the workspace.
5. Re-test the question and nearby phrasings.

## Important

Do not use a verified fact to override security rules or to store secrets. It is knowledge content, not an authorization mechanism.

## Troubleshooting

If this control is not visible in the current UI build, use the normal Knowledge source workflow instead; do not invent a client-side shortcut.
