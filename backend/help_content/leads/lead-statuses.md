# Lead statuses

Lead status helps the workspace track where a captured contact is in the follow-up process.

## Before you start

This guide is available to all authenticated workspace roles.

## How to use status

Treat the status displayed in **Leads** as operational metadata. Update it only when the lead actually changes stage. Keep status changes separate from agent instructions and knowledge so reporting stays understandable.

## What happens next

Status changes can be used by the current Leads experience and future workflow integrations without changing the original conversation record.

## Troubleshooting

If the status control is disabled or the backend rejects the change, confirm your role has lead write access: Owner, Admin, or Member.
