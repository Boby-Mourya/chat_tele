# Choose the agent to deploy

The Deploy workspace edits and previews one selected agent at a time.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Steps

1. Open **Deploy**.
2. Use the agent selector in the deployment workspace.
3. Confirm the agent name/avatar and its intended **Deployment channel**.
4. If the agent was duplicated for a new channel, verify you selected the duplicate rather than the original.
5. Make deployment changes only after confirming the correct agent.

## What happens next

The preview and channel controls update for the selected agent.

## Troubleshooting

If changes appear on the wrong bot, stop and reselect the intended agent before saving further configuration.
