# Deploy an agent to a website

1. Open **Deploy**.
2. Select the website agent.
3. Review desktop/mobile preview.
4. Open embed/install options.
5. Copy the generated snippet into the intended site.
6. If allowed domains are configured, include the real site hostname.
7. Test the widget from the deployed site.
