# Preview a website deployment

Previewing helps catch configuration mistakes before a deployment reaches users.

## Before you start

This guide is available to all authenticated workspace roles.

## Steps

1. Open **Deploy** and select the intended agent.
2. Choose the matching deployment channel.
3. Use the **Desktop preview** and **Mobile preview** buttons. Check launcher position, widget open/closed state, welcome text, colors, localization, and the selected agent.
4. Verify welcome content and representative answers.
5. Confirm the channel connection state when the integration requires one.

## Important

A preview proves the configured template renders; it does not prove an external provider connection is live. Verify **Integrations** as well.

## Troubleshooting

If the preview looks wrong, first confirm the selected agent and its stored deployment channel before changing global settings.
