# Fix a widget domain-not-allowed problem

1. Open the agent security/settings area.
2. Review **Allowed domains**.
3. Add the exact hostname used by the deployed website.
4. Save the change.
5. Reload and retest the site.

Do not add domains you do not control merely to bypass a configuration error.
