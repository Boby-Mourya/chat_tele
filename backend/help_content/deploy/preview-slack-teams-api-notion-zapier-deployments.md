# Preview Slack/Teams/API/Notion/Zapier deployments

Northstar provides channel-specific templates for Slack, Microsoft Teams, Developer API, Notion, and Zapier so duplicated/created agents keep the correct destination context.

## Before you start

This guide is available to all authenticated workspace roles.

## Steps

1. Open **Deploy** and select the agent.
2. Choose the destination from **Deployment channel**.
3. Review the channel-specific preview/setup panel.
4. Check **Integrations** for actual availability. **Microsoft Teams** is currently marked **Coming soon** in the marketplace.
5. For Developer API, use server-side API credentials rather than a browser secret.
6. For Notion/Zapier, enable/connect only when the integration card permits it.

## Troubleshooting

A saved channel template does not override a **Coming soon** or disconnected integration state.
