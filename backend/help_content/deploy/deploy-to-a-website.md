# Deploy to a website

Use the Website deployment flow to configure the widget, preview it, and install it on an approved domain.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Steps

1. Open **Deploy** and select the agent.
2. Choose **Website widget** as the deployment channel.
3. Configure appearance, launcher behavior, starters, localization, privacy, and other Website options as needed.
4. Add **Allowed domains** for protected public deployment.
5. Open **Instant embed** or **IFrame embed**.
6. Copy the generated code and install it on the site.
7. Test on the actual domain in desktop and mobile browsers.

## Troubleshooting

If the widget is missing, use the built-in diagnostic helper and check the allowlist/CSP/browser console.
