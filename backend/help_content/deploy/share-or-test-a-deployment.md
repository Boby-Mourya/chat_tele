# Share or test a deployment

Before sharing a deployment, test the exact surface your customers will use.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Checklist

1. Confirm the correct agent and channel are selected.
2. Test supported questions and one unsupported question.
3. Verify citations when enabled.
4. Check the mobile layout.
5. For Website, test on an **Allowed domain** using the real embed.
6. For integrations, confirm the channel is **Connected** and not **Coming soon**.
7. Verify consent/privacy copy for public deployments.

## What happens next

Share the deployment only after the real-channel test succeeds. Keep the Help Center/support path available for operators who need recovery guidance.
