# Handle an escalated conversation

An **escalated** conversation needs human attention because the automated path should not continue alone.

## Before you start

Workspace **Owner**, **Admin**, or **Member** access is required for the action steps.

## Steps

1. Open the escalated conversation from **Conversations**.
2. Read the full recent context, including what the assistant could not resolve.
3. Reply as a human teammate when a response is required.
4. Avoid changing agent knowledge inside the conversation itself; fix reusable knowledge separately under the agent's **Knowledge** tab.
5. Resolve the conversation after the issue is complete.

## What happens next

Repeated escalations for the same question are a signal to improve Help/Knowledge content or agent instructions.
