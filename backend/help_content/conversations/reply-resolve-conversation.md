# Reply to and resolve a conversation

## Before you start

You need an Owner, Admin, or Member role.

1. Open **Conversations** and select the thread.
2. Review recent messages and citations.
3. Send the permitted human response.
4. Choose **Resolve** when complete.
5. Use **Reopen** if more work is needed later.
