# Understand citations in responses

Citations connect a grounded assistant answer back to the source material that supported it.

## Before you start

This guide is available to all authenticated workspace roles.

## How citations work

When the agent's citation mode is enabled and retrieved evidence contains a usable source reference, the response can include citations. Citations are not created from unrelated customer content and should not be treated as proof when the source itself is outdated.

## Review a cited answer

1. Read the answer first.
2. Open or inspect the cited source where available.
3. Confirm the cited content actually supports the claim.
4. If the citation is wrong or missing, review the underlying Knowledge source and retrieval quality.

## Troubleshooting

If citations are consistently absent, check the agent's **Settings → LLM connection → Citations** control and make sure the answer is being grounded by connected knowledge.
