# Disconnect WhatsApp

Disconnecting removes the Northstar workspace's active WhatsApp integration configuration.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Steps

1. Open **Integrations**.
2. Find **WhatsApp** and select **Manage**.
3. Confirm which business/account/agent connection is active.
4. Use the disconnect action provided by the integration modal.
5. Confirm the Integrations card no longer reports **Connected**.
6. Check **Deploy** so users are not directed to a disconnected channel.

## Important

Disconnect only when the channel is no longer needed or when you are intentionally re-authorizing it.

## Troubleshooting

If the card remains connected after a successful disconnect, refresh the page and verify the backend integration status rather than repeatedly clicking the action.
