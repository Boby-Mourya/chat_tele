# Troubleshoot WhatsApp connection status

1. Verify the WhatsApp connection status for the intended agent in **Integrations**.
2. Confirm Embedded Signup completed.
3. Confirm the selected WABA/phone number belongs to the expected Meta Business account.
4. Check the two-step verification PIN step if requested.
5. Verify deployment webhook/integration configuration.

If the issue continues, send a support request with non-secret diagnostic context only.
