# Slack, Instagram, Facebook, Teams, Notion and Zapier availability

Northstar exposes several deployment/integration destinations, but availability is not identical for every channel.

## Current workspace surfaces

- **Slack** — channel integration/deployment surface.
- **Instagram** — messaging deployment surface.
- **Facebook Messenger / Facebook / Meta** — messaging deployment surface.
- **Notion** — knowledge-sync integration surface.
- **Zapier** — automation/workflow integration surface.
- **Microsoft Teams** — currently marked **Coming soon** in the Integrations marketplace.

The Agent creation/duplication flow can still store these deployment-channel templates so the matching preview/setup experience is preserved.

## Important

Do not assume a channel is live only because it can be selected as an agent template. Check **Integrations** and **Deploy** for its actual connection/Coming soon state.
