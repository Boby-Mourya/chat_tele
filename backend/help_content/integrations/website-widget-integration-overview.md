# Website widget integration overview

The **Website widget** is the built-in web channel and is available from both the agent deployment tools and the **Deploy** workspace.

## Before you start

This guide is available to all authenticated workspace roles.

## Main pieces

- Agent appearance and welcome content.
- **Allowed domains** protection.
- JavaScript **Instant embed**.
- **IFrame embed** for a full embedded chat surface.
- Desktop/mobile preview.
- Widget enable/launcher/localization/privacy settings in Deploy.

## What happens next

Install the generated snippet on an allowed site, then test the real page in addition to the built-in preview.

## Troubleshooting

If the widget does not appear, use the Deploy diagnostic helper and check agent status, the exact domain allowlist, CSP, and browser console.
