# Workspace profile and preferences

The **Workspace profile** stores organization details and regional preferences shared across the workspace.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Available controls

- **Workspace name**
- **Workspace slug**
- **Timezone**
- **Date format**
- **Default workspace language**

## Steps

1. Open **Workspace**.
2. Edit the required profile/preferences fields.
3. Save the workspace settings.
4. Refresh another page and verify the setting is reflected where the product uses it.

## Troubleshooting

The workspace slug accepts a restricted lowercase/digit/hyphen format in the current UI. Invalid characters are removed as you type.
