# API keys overview

Workspace API keys are managed from **Workspace**. Create or revoke keys only when your role allows it.

Treat a newly displayed secret as sensitive. Store it in your approved secret manager and never put it in Help requests, Help AI questions, screenshots, agent instructions, or knowledge sources. Revoke and replace any key that may be exposed.
