# Configure white-label support contact

1. Open **Workspace** and then **White Label**.
2. Set **Support email** if Help requests should route to a custom workspace address.
3. Optionally set **Support URL** as an additional external resource.
4. Save changes.

The internal Help Center stays available. If no custom support email is configured, Northstar falls back to `support@northstar.ai`.
