# Billing and usage overview

The current **Workspace → Plan & billing** section summarizes plan/usage information.

## Before you start

This guide is available to all authenticated workspace roles.

## Current view

The page shows usage examples for **Conversations**, **AI agents**, and **Team members**, plus **Manage billing** and **Compare plans** actions.

## Important current limitation

The current frontend explicitly reports that the billing portal will open **after a payment provider is connected**. Treat the displayed billing controls as the product's current plan/usage surface, not proof that a live payment-provider portal is already integrated.

## Troubleshooting

If Manage billing only shows an informational message, that is the current implemented behavior until the payment-provider integration is connected.
