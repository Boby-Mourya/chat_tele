# Custom domain and branding

Northstar exposes custom-domain and branding controls for workspace/agent experiences where the current deployment supports them.

## Before you start

Workspace **Owner** or **Admin** access is required.

## Steps

1. Open **Workspace → White Label** for workspace branding.
2. Configure company/logo/color fields as needed.
3. For the agent Website deployment, use the Deploy **Custom domain** field where appropriate.
4. Follow the UI instruction to create the required DNS/CNAME record after saving a custom domain.
5. Verify the resolved host before directing users to it.

## Troubleshooting

DNS changes are external to Northstar and may not become reachable immediately. Keep the standard deployment available while validating a new custom domain.
